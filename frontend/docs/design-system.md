# AI Studio — Design System

> Версия 1.0

---

# Принципы

AI Studio — профессиональный AI Workspace.

Интерфейс должен ощущаться как современный desktop-продукт уровня:

- ChatGPT
- Claude
- Cursor
- Midjourney
- Runway
- Linear
- Raycast

Основные качества интерфейса:

- минимализм;
- очень много воздуха;
- спокойные теплые цвета;
- большие скругления;
- тонкие границы;
- отсутствие визуального шума;
- максимум внимания контенту.
